
# 🚀 AWS EC2 (Elastic Compute Cloud) – Complete Guide

---

## 🖥️ What is Amazon EC2?

Amazon EC2 (Elastic Compute Cloud) is a web service that provides **resizable compute capacity in the cloud**.

👉 It allows you to run virtual servers (instances) without managing physical hardware.

---

## ✨ Key Features of EC2

- 🔄 Easily scale instances up or down
- 💰 Pay-as-you-go pricing model
- 🧩 Multiple instance types for different workloads

---

## 🧠 EC2 Instance Types (Use Cases)

| Use Case | Instance Type |
|----------|--------------|
| 🌐 Websites & Small Apps | General Purpose (t3, m5) |
| ⚡ High CPU Workloads | Compute Optimized (c5, c6i) |
| 🗄️ Databases & Caching | Memory Optimized (r5, x2idn) |
| 📊 Big Data & Storage | Storage Optimized (i3, d3) |
| 🤖 AI/ML & Gaming | GPU (p4, g5) |

---

## 🔑 Key Pair (Security)

- Public Key → Stored in AWS
- Private Key → Downloaded by user

👉 Used to securely connect:
- Linux → SSH
- Windows → RDP

---

## 💰 EC2 Pricing Models

- 🟢 On-Demand → Pay per usage
- 🔵 Reserved → Lower cost (long-term)
- 🟡 Spot → Cheapest (can terminate anytime)
- 🟣 Savings Plans → Flexible discounts

---

## 🛑 Stop vs Terminate

| Action | Result |
|-------|--------|
| Stop | Instance shuts down (data safe) |
| Terminate | Instance deleted (data lost) |

---

## 🌐 Elastic IP

- Static public IP address
- Remains same even after restart

---

## 🔥 Security Group

- Acts as a **firewall**
- Controls inbound & outbound traffic

---

## 🔗 Connect to EC2

### Linux (SSH)
ssh -i key.pem ec2-user@<public-ip>

### Windows (RDP)
- Use Remote Desktop
- Login with username & password

---

## 💾 Storage (EBS vs Instance Store)

| Feature | EBS | Instance Store |
|--------|-----|----------------|
| Persistence | ✅ Yes | ❌ No |
| Data Safety | Retained | Lost on stop |

---

## 📈 Auto Scaling

- Automatically adds/removes instances
- Maintains performance & reduces cost

---

## ⚖️ Load Balancer (ELB)

- Distributes traffic across instances
- Ensures high availability

---

## 🔄 Scaling Types

- 🔼 Vertical Scaling → Increase instance size
- 🔁 Horizontal Scaling → Add more instances

---

## 📦 AMI (Amazon Machine Image)

- Pre-configured template (OS + apps)
- Used to launch instances

### ✅ Benefits
- Fast setup
- Consistency

### 🛠️ Create AMI
- EC2 → Actions → Image → Create Image

---

## 🔐 Networking & Security

- Elastic IP → Static IP
- Security Groups → Firewall
- NACL → Subnet-level control
- Snapshot → EBS backup

---

## 🌍 Public vs Private IP

| Type | Use |
|------|-----|
| Public IP | Internet access |
| Private IP | Internal VPC communication |

---

## 🏗️ High Availability

- Deploy across multiple AZs
- Use Load Balancer

---

## 🛠️ Troubleshooting

- Instance terminated → Restore using AMI/Snapshot
- Slow instance → Check CPU/Memory, upgrade type

---

## 🔗 EC2 to RDS Secure Connection

1. Same VPC
2. RDS in Private Subnet
3. Security Group rules (3306 / 5432)
4. IAM Roles

---

## 🚀 Steps to Launch EC2

1. Login to AWS Console
2. Open EC2
3. Click Launch Instance
4. Choose AMI (Amazon Linux / Ubuntu)
5. Select Instance Type (t2.micro)
6. Create Key Pair
7. Configure Network
8. Add Storage
9. Review & Launch
