## ⚡ Subnets in AWS VPC — Rapid Fire Q&A

| 🔢 Q#   | ❓ Question                                        | 💡 Answer                                                                                                                                                                                           |
| ------- | --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🔹 Q1   | What is a subnet in AWS?                           | 👉 A logical subdivision of a Amazon Web Services VPC IP range.                                                                                                                                     |
| 🔹 Q2   | Why do we use subnets?                             | 👉 To organize, isolate, and secure resources within a VPC.                                                                                                                                         |
| 🔹 Q3   | Are subnets region-specific?                       | 👉 ❌ No — they are Availability Zone–specific.                                                                                                                                                      |
| 🌐 Q4   | Types of subnets?                                  | 👉 Public and Private                                                                                                                                                                               |
| 🌐 Q5   | What is a public subnet?                           | 👉 Subnet with route to Internet Gateway (IGW).                                                                                                                                                     |
| 🌐 Q6   | What is a private subnet?                          | 👉 No direct route to internet.                                                                                                                                                                     |
| 🌍 Q7   | How do instances in public subnet access internet? | 👉 Via Internet Gateway + public IP.                                                                                                                                                                |
| 🌍 Q8   | How do private subnet instances access internet?   | 👉 Via NAT Gateway (outbound only).                                                                                                                                                                 |
| 🌍 Q9   | Can private subnet have inbound internet access?   | 👉 ❌ No (by design).                                                                                                                                                                                |
| 📐 Q10  | How is subnet CIDR defined?                        | 👉 Subset of VPC CIDR block.                                                                                                                                                                        |
| 📐 Q11  | Example?                                           | 👉 VPC: 10.0.0.0/16 → Subnet: 10.0.1.0/24                                                                                                                                                           |
| 📐 Q12  | Reserved IPs in subnet?                            | 👉 5 IPs reserved by AWS.                                                                                                                                                                           |
| 🧭 Q13  | What determines subnet behavior?                   | 👉 Route table association.                                                                                                                                                                         |
| 🧭 Q14  | Can multiple subnets share a route table?          | 👉 ✅ Yes                                                                                                                                                                                            |
| 🔐 Q15  | Subnet-level security?                             | 👉 Network ACL (NACL)                                                                                                                                                                               |
| 🔐 Q16  | Instance-level security?                           | 👉 Security Groups                                                                                                                                                                                  |
| 🏢 Q17  | Can a subnet span multiple AZs?                    | 👉 ❌ No                                                                                                                                                                                             |
| 🏢 Q18  | Why create subnets in multiple AZs?                | 👉 High availability.                                                                                                                                                                               |
| ☸️ Q19  | Why multiple subnets in EKS?                       | 👉 For high availability across AZs.                                                                                                                                                                |
| ☸️ Q20  | Public vs private subnets in EKS?                  | 👉 Public = Load Balancers <br> 👉 Private = Worker nodes                                                                                                                                           |
| ⚙️ Q21  | What is subnet auto-assign public IP?              | 👉 Automatically assigns public IP to instances.                                                                                                                                                    |
| ⚙️ Q22  | What is route propagation?                         | 👉 Dynamic routing updates (VPN/Direct Connect).                                                                                                                                                    |
| 🛠️ Q23 | Instance not reachable?                             | 👉 Check: Route table, IGW/NAT, Security Group, NACL                                                                                                                                                |
| 🛠️ Q24 | No internet from private subnet?                    | 👉 Check NAT Gateway + route.                                                                                                                                                                       |
| 🏗️ Q25 | Typical 3-tier architecture subnets?                | 👉 Public → Load Balancer <br> Private → App servers <br> Private → Database                                                                                                                        |
| 🎯 Q26  | How to make subnet public?                         | 👉 Attach route table with IGW route.                                                                                                                                                               |
| 🎯 Q27  | Why not place DB in public subnet?                 | 👉 Security risk.                                                                                                                                                                                   |
| 🎯 Q28  | Can a subnet be both public & private?             | 👉 ❌ No — depends on route table.                                                                                                                                                                   |
| 🔥 Q29  | Pro Tips (Interview Gold)                          | ✔ Always use private subnets for backend & DB <br> ✔ Use NAT Gateway for outbound internet <br> ✔ Design across multiple AZs <br> ✔ Keep public exposure minimal <br> ✔ Use proper CIDR planning |

## ⚡ Route Tables in AWS VPC — Rapid Fire Q&A

| 🔢 Q#   | ❓ Question                                     | 💡 Answer                                                                                                                                                                                |
| ------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🔹 Q1   | What is a Route Table?                         | 👉 A set of rules (routes) that determine where network traffic is directed.                                                                                                             |
| 🔹 Q2   | Where are route tables used?                   | 👉 Inside a Amazon Web Services VPC.                                                                                                                                                     |
| 🔹 Q3   | What does a route contain?                     | 👉 Destination CIDR + target (gateway/resource).                                                                                                                                         |
| 🧠 Q4   | What is a destination?                         | 👉 IP range (e.g., 0.0.0.0/0 for internet).                                                                                                                                              |
| 🧠 Q5   | What is a target?                              | 👉 Resource handling traffic (IGW, NAT, etc.).                                                                                                                                           |
| 🧠 Q6   | Default route table?                           | 👉 Automatically created with VPC.                                                                                                                                                       |
| 🌐 Q7   | Local route?                                   | 👉 Enables communication within VPC (auto-added).                                                                                                                                        |
| 🌐 Q8   | Internet route?                                | 👉 0.0.0.0/0 → Internet Gateway (IGW)                                                                                                                                                    |
| 🌐 Q9   | Private subnet route?                          | 👉 0.0.0.0/0 → NAT Gateway                                                                                                                                                               |
| 🔗 Q10  | What is route table association?               | 👉 Linking subnet to a route table.                                                                                                                                                      |
| 🔗 Q11  | Can a subnet have multiple route tables?       | 👉 ❌ No — only one at a time.                                                                                                                                                            |
| 🔗 Q12  | Can a route table serve multiple subnets?      | 👉 ✅ Yes                                                                                                                                                                                 |
| 🌍 Q13  | What makes a subnet public?                    | 👉 Route to IGW.                                                                                                                                                                         |
| 🌍 Q14  | What makes a subnet private?                   | 👉 Route to NAT Gateway or no internet route.                                                                                                                                            |
| 🔌 Q15  | Common targets?                                | 👉 Internet Gateway <br> NAT Gateway <br> VPC Peering <br> Transit Gateway                                                                                                               |
| 🚀 Q16  | What is VPC Peering route?                     | 👉 Route traffic to another VPC.                                                                                                                                                         |
| 🚀 Q17  | What is Transit Gateway route?                 | 👉 Central hub routing for multiple VPCs.                                                                                                                                                |
| ⚠️ Q18  | What is blackhole route?                       | 👉 Route with unavailable target.                                                                                                                                                        |
| 🔐 Q19  | Does route table provide security?             | 👉 ❌ No — only routing (use SG/NACL for security).                                                                                                                                       |
| 🛠️ Q20 | Instance not accessing internet?               | 👉 Check: Route table (0.0.0.0/0), IGW/NAT, Subnet association                                                                                                                           |
| 🛠️ Q21 | Traffic not reaching another subnet?           | 👉 Check local route and CIDR overlap.                                                                                                                                                   |
| ☸️ Q22  | How do route tables affect EKS?                | 👉 Control pod/node connectivity.                                                                                                                                                        |
| ☸️ Q23  | Why correct routing is critical?               | 👉 Ensures communication between services and internet.                                                                                                                                  |
| 🎯 Q24  | Why is subnet not public despite IGW attached? | 👉 Missing route to IGW.                                                                                                                                                                 |
| 🎯 Q25  | Why private instance cannot access internet?   | 👉 Missing NAT Gateway route.                                                                                                                                                            |
| 🎯 Q26  | Can you have multiple default routes?          | 👉 ❌ No — one per destination.                                                                                                                                                           |
| 🔥 Q27  | Pro Tips (Interview Gold)                      | ✔ Always verify subnet association <br> ✔ Public subnet = IGW route <br> ✔ Private subnet = NAT route <br> ✔ Route tables don’t provide security <br> ✔ Avoid overlapping CIDR ranges  |
| 🚀 Q28  | Quick Summary                                  | 👉 Route Table = Traffic controller of VPC <br> 👉 Maps destination → target <br> 👉 Key to defining public vs private subnets                                                           |

## ⚡ Internet Gateway (IGW) in AWS VPC

| 🔢 Q#   | ❓ Question                                            | 💡 Answer                                                                                                                                                                                                                                                   |
| ------- | ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🔹 Q1   | What is an Internet Gateway (IGW)?                    | 👉 A horizontally scaled, managed gateway that enables communication between a VPC and the internet.                                                                                                                                                        |
| 🔹 Q2   | Where is IGW used?                                    | 👉 Attached to a Amazon Web Services VPC.                                                                                                                                                                                                                   |
| 🔹 Q3   | Is IGW managed by AWS?                                | 👉 ✅ Yes (highly available and scalable).                                                                                                                                                                                                                   |
| 🌐 Q4   | What are the two main roles of IGW?                   | 👉 Provides internet access <br> Performs NAT for public IPs                                                                                                                                                                                                |
| 🌐 Q5   | Does IGW assign public IPs?                           | 👉 ❌ No — it only routes traffic.                                                                                                                                                                                                                           |
| 🧭 Q6   | How is IGW used in routing?                           | 👉 Route table entry: 0.0.0.0/0 → IGW                                                                                                                                                                                                                       |
| 🧭 Q7   | What happens without route to IGW?                    | 👉 No internet access, even if IGW is attached.                                                                                                                                                                                                             |
| 🌍 Q8   | What makes a subnet public?                           | 👉 Route to IGW + public IP on instances.                                                                                                                                                                                                                   |
| 🌍 Q9   | Can a private subnet use IGW directly?                | 👉 ❌ No                                                                                                                                                                                                                                                     |
| 🔄 Q10  | Is IGW bidirectional?                                 | 👉 ✅ Yes (inbound & outbound traffic allowed).                                                                                                                                                                                                              |
| 🔄 Q11  | Can IGW restrict traffic?                             | 👉 ❌ No — use Security Groups/NACL.                                                                                                                                                                                                                         |
| 📌 Q12  | What is required for internet access via IGW?         | 👉 Public IP or Elastic IP.                                                                                                                                                                                                                                 |
| 📌 Q13  | What is Elastic IP?                                   | 👉 Static public IP address.                                                                                                                                                                                                                                |
| ⚙️ Q14  | How many IGWs per VPC?                                | 👉 One IGW per VPC.                                                                                                                                                                                                                                         |
| ⚙️ Q15  | Can IGW be shared across VPCs?                        | 👉 ❌ No                                                                                                                                                                                                                                                    |
| ⚖️ Q16  | Comparison: IGW vs NAT Gateway                        | 👉 IGW: Inbound + Outbound, requires public IP, used by public subnet <br> NAT Gateway: Outbound only, no public IP required for instances, used by private subnet                                                                                          |
| 🛠️ Q17 | Instance not reachable from internet?                 | 👉 Check: Public IP assigned, Route to IGW, Security Group, NACL                                                                                                                                                                                            |
| 🛠️ Q18 | Can ping internet but not access app?                 | 👉 Check inbound rules in Security Group.                                                                                                                                                                                                                   |
| ☸️ Q19  | How IGW is used in EKS?                               | 👉 Public Load Balancers use IGW for external access.                                                                                                                                                                                                       |
| ☸️ Q20  | Where do worker nodes typically run?                  | 👉 Private subnets (use NAT instead of IGW).                                                                                                                                                                                                                |
| 🎯 Q21  | Why instance in public subnet not accessing internet? | 👉 Missing public IP or route table entry.                                                                                                                                                                                                                  |
| 🎯 Q22  | Why inbound traffic not working?                      | 👉 Security Group/NACL blocking.                                                                                                                                                                                                                            |
| 🎯 Q23  | Can IGW alone make subnet public?                     | 👉 ❌ No — route table + public IP required.                                                                                                                                                                                                                |
| 🔥 Q24  | Pro Tips (Interview Gold)                             | ✔ IGW does NOT provide security <br> ✔ Always combine IGW + route table + public IP <br> ✔ Use private subnets for backend workloads <br> ✔ Avoid exposing instances directly — use Load Balancers <br> ✔ Always verify routing first in troubleshooting   |
| 🚀 Q25  | Quick Summary                                         | 👉 IGW = Bridge between VPC and Internet <br> 👉 Enables inbound + outbound traffic <br> 👉 Works only with public subnets + route tables                                                                                                                   |
